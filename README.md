# Secrets — Free Offline Installer

![Category](https://img.shields.io/badge/Password_Manager-blue?style=flat-square)

## About

Secrets is a macOS and iOS password manager with a clean native interface. Store passwords, secure notes, credit cards, and identities in an encrypted vault that syncs across Apple devices via iCloud. With Safari and third-party browser integration for autofill, Secrets provides a polished Apple-native password management experience for users who prefer locally-stored vaults over cloud services.

## Common Problems & Limitations

- **Apple Only** — macOS and iOS only; no Windows or Android cross-platform access
- **iCloud Dependency** — Cross-device sync requires iCloud
- **Browser Support** — Best browser integration with Safari; other browsers less seamless
- **Commercial License** — Paid application
